# Authentication & Digital Seals

## Authentication
- JWT-based (access + refresh tokens)
- 2FA support (TOTP + Email OTP)
- Impersonation for admins
- JWT blacklist for revocation

## Digital Signatures
- User signatures stored in `ExecutiveSignature`
- Settings UI: `SignatureSettingsCard` component
- Stored as base64 data URLs in `signature_payload` on minutes

## Executive Seals
- Applied only on APPROVE minutes by executives
- Grade check: `MDCS`, `EDCS`, `MSS1`, `MSS2`, `MSS3`
- Role check: "Managing Director", "Executive Director", "General Manager", "Principal Manager"
- Generated by `SealGenerationService.generate_seal()`
- Stored in `DocumentSeal`, linked via `Minute.seal_applied`

## Seal Verification
- Public verification endpoint: `/api/verify/[serial]/`
- `SealVerificationView` with QR code
- Public page: `/verify/[serial]`

## Constants
- `EXECUTIVE_GRADES` in `common/grade_utils.py`
- `SYSTEM_ROLE_SUPER_ADMIN` in `lib/constants.ts`
