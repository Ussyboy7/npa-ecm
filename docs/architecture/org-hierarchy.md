## Hierarchy Flow

```
Directorate (ED/MD)
  └── Division (GM)
      └── Department (AGM/HoD)
          └── Users
```

### Routing Rules

1. **Downward Routing**: Can route to lower levels in same division/directorate
2. **Upward Routing**: Can route to higher levels in same division/directorate
3. **Lateral Routing**: Can route to same grade level peers (if `allow_lateral_routing` enabled)
4. **Cross-Tier Routing**: AGM can route to GM (one level up)

### Data Flow

- Users can have: `directorate`, `division`, `department`
- If `directorate` not set, derived from `division.directorate`
- If `division` not set, derived from `department.division`
- Hierarchy validated: `division.directorate == user.directorate`
- Hierarchy validated: `department.division == user.division`
